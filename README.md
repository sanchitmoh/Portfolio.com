# Sanchit Mohite - Portfolio

A modern, animated portfolio website built with Next.js and Framer Motion, featuring a sleek glossy black design with smooth animations throughout.

## Features

- 🎨 Glossy black background with grey/white color scheme
- ✨ Smooth Framer Motion animations on every element
- 📱 Fully responsive design
- ⚡ Built with Next.js 14 and TypeScript
- 🎯 Modern UI with glassmorphism effects
- 🚀 Optimized performance

## Tech Stack

- **Framework:** Next.js 14
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Deployment:** Ready for Vercel/Netlify

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Sections

- **Hero:** Animated introduction with call-to-action buttons
- **About:** Personal information with animated skill bars
- **Skills:** Technology stack with hover animations
- **Projects:** Featured projects with interactive cards
- **Contact:** Contact form and social links

## Customization

- Update personal information in each component
- Modify colors in `tailwind.config.js`
- Add your own projects in `components/Projects.tsx`
- Update contact information in `components/Contact.tsx`

## Deployment

The portfolio is ready to deploy on platforms like Vercel, Netlify, or any static hosting service.

```bash
npm run build
```
